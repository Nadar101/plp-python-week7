
# Week 7 Assignment: File Handling and CSV Reports

## Project Files

- `my_notes.py` - Writes, appends, reads, and counts notes.
- `my_notes.txt` - Stores the four notes.
- `report_builder.py` - Reads CSV data and generates a learner report.
- `hubs.csv` - Contains learner names, hubs, and scores.
- `report.txt` - Contains the learner report and average score.
- `README.md` - Describes the assignment and project files.

## Question: What happens if "a" is changed to "w"?

Changing "a" to "w" would overwrite the existing file instead of adding a new note. The first three notes would be erased when the fourth note is written.
